📡 Panduan Memasang Google Sheet Tracking Pembeli

Ikuti 5 langkah mudah berikut untuk menghubungkan software ke Spreadsheet pribadi Anda (Hanya 2 Menit):

  1. Buka sheets.google.com ↗ dan buat Spreadsheet Baru (Beri judul: Database Pembeli & Lisensi PitaMedia).
  2. Di menu atas spreadsheet Anda, klik: Ekstensi (Extensions) > Apps Script.
  3. Hapus semua teks default di Apps Script, lalu Tempel (Paste) Kode Script di bawah ini.
  4. Klik tombol biru Terapkan (Deploy) > Penerapan baru (New deployment):
    • Pilih jenis: Aplikasi Web (Web App)
    • Siapa yang memiliki akses: Siapa saja (Anyone) (Wajib agar aplikasi pembeli bisa mengirim data aktivasi)
  5. Klik Terapkan (Deploy), berikan izin akses Google Anda, lalu Salin URL Aplikasi Web yang diberikan dan tempelkan ke kolom Master Webhook di tab Pengaturan aplikasi ini.
